User Guide

🚀 Getting Started

Learn how to use Matrix Led measurement tool

Workflow

  1. Start: Click "Gét Gô" on the main screen.
  2. Fullscreen: Use for most accurate measurements. Exit with Esc.

Core Features

  • Rulers: Real-time pixel rulers on all 4 edges.
  • Guidelines: Toggle with G to see precise intersection coordinates.
  • Custom Shapes: Press S to open settings and draw reference rectangles.
  • Background Overlay: Upload design mockups to compare with your live implementation.

Keyboard Controls

  • G — Toggle Guidelines
  • S — Settings Panel
  • Esc — Exit / Close
